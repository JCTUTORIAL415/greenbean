水林地瓜 ERP 技術文件

本文件說明水林地瓜農業 ERP 平台的技術架構、模組設計、資料結構與系統整合規範，供開發人員及技術主管參考。

版本 1.0 純前端 HTML/CSS/JS localStorage 持久化 7 個子系統

1. 系統概覽

水林地瓜 ERP 是一套專為農業生產企業設計的輕量級企業資源規劃系統。系統以 純 HTML / CSS / JavaScript 實作，無需後端伺服器、無需框架、可在任何現代瀏覽器直接開啟使用。

ⓘ
設計理念：優先快速部署與離線使用。所有資料存於瀏覽器 localStorage，同一台電腦/瀏覽器的所有系統共享同一份資料，實現即時跨模組同步。

系統範圍

平台覆蓋農業企業的以下主要業務流程：

  • 農田端：農民資料建檔、地塊管理、作物紀錄
  • 倉儲端：品種建檔、入出庫管理、冷凍艙控制
  • 加工端：加工批次管理、選果機作業、品管記錄
  • 銷售端：電商前台、訂單管理、庫存自動扣減
  • 人資端：出勤打卡、請假審核、薪資計算
  • 獎勵端：獎金機制建立、考核連動、薪資核對
  • 管理端：總後台入口、人員帳號、系統權限

登入驗證流程

// 每個子系統的標準登入流程
function doLogin() {
  // 1. 讀取使用者輸入
  const account = getElementById('loginAccount').value;
  const password = getElementById('loginPassword').value;

  // 2. 比對 slg_users（由總後台人員管理維護）
  const users = JSON.parse(localStorage.getItem('slg_users') || '[]');
  const user = users.find(u =>
    u.account === account && u.password === password && u.status === 'active'
  );
  if (!user) { showToast('帳號或密碼錯誤'); return; }

  // 3. 查詢 slg_user_perms 確認此系統存取等級
  const perms = JSON.parse(localStorage.getItem('slg_user_perms') || '{}');
  const perm = (perms[user.id] || {})['SYSTEM_ID'] || 'none';
  if (perm === 'none') { showToast('無存取權限'); return; }

  // 4. 寫入 sessionStorage，觸發畫面顯示
  sessionStorage.setItem('xxx_role', perm === 'supervisor' ? '主管' : '人員');
  sessionStorage.setItem('xxx_name', user.name);
  applyLogin();
}

4. 總後台

統一的管理員入口，提供系統全局視角與人員管理能力。

頁面功能

  • 系統總覽：7 個子系統入口卡，即時顯示各系統關鍵數字
  • 人員管理：員工帳號 CRUD，設定各系統存取等級（無權限 / 唯讀 / 人員 / 主管）
  • 權限矩陣：全員 × 全系統的二維視圖，可按部門篩選
  • 系統設定：管理員帳號 / 密碼更改、JSON 全量備份下載、權限重置

8. 銷售系統

電商前台 + 後台訂單管理，訂單確認自動扣倉庫庫存。

庫存計算邏輯

// 加工類產品可用庫存 = 加工產出量 - 已售出量
function calcProcStock(sourceId, spec) {
  const inQty  = getProcRecs().filter(r => r.productId === sourceId)
                               .reduce((s,r) => s + r.netWeight, 0);
  const outQty = getWhOut().filter(o =>
    o.productId === sourceId && o.productType === 'processed'
  ).reduce((s,o) => s + o.qty, 0);
  return Math.max(0, inQty - outQty);
}

訂單狀態流轉

pending → confirmed → packing → shipped → done / cancelled

確認訂單時，系統自動將每個品項寫入 slg_wh_out；取消訂單時，刪除對應 orderId 的出庫記錄。

9. 主管後台

員工出勤、請假、薪資計算。

薪資計算規則（參考）

  • 正常工時上限：每日 8 小時（至 17:00）
  • 加班費：第一段 × 1.34，第二段 × 1.67（依勞基法）
  • 午餐扣除：12:00 – 13:00；晚餐 18:30 – 19:00
  • 獎金加總：讀取 slg_bonus_records（status = paid）

存取等級說明

等級值說明對應子系統角色
無權限none無法登入該系統登入時直接拒絕

⚠

14. 硬體 API 預留點

加工系統的選果機器介面預留了 PLC / IoT 感測器的串接入口，以標準化的方式等待未來實作：

// === 機器 API 串接預留 ===
// 以下為未來 PLC / 感測器串接的 fetch 範本，目前以模擬資料取代

async function fetchMachineStatus(machine) {
  if (!machine.apiEndpoint) return null; // 無設定 endpoint 時略過
  try {
    const res = await fetch(machine.apiEndpoint + '/status');
    const data = await res.json();
    // 回傳欄位：waterTemp, flowRate, beltSpeed, lineSpeed,
    //           humidity, ambientTemp, cycleTime
    updateMachineDisplay(data);
  } catch(e) {
    console.warn('機器離線，切換為手動模式', e);
  }
}

// machineData 結構（預留欄位以 null 佔位）：
machineData: {
  waterTemp:   null,  // °C
  flowRate:    null,  // L/min
  beltSpeed:   null,  // m/s
  machineId:   null,
  lineSpeed:   null,  // ← 留水線預留
  humidity:    null,
  ambientTemp: null,
  cycleTime:   null
}

選果機器設定介面

加工系統 → 選果設定 → 機器管理，可設定機器名稱與 API Endpoint URL，系統啟動時自動嘗試連線。
