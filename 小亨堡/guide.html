01 · 介紹

小亨堡QA 是什麼？

小亨堡QA 是媽咪的居家照護助手，整理了寶寶常見問題與急救步驟，幫你在第一時間判斷狀況，不再被半夜的小小不對勁逼瘋。

核心精神：「看活力 ＞ 看溫度」
寶寶會玩、會笑、有食慾、尿量正常 = 大多沒事；嗜睡、不哭不鬧、皮膚異常 = 才是該擔心的紅旗。
02 · 紅綠燈系統

三種顏色，三種處理方式

每一題 QA 都標好了顏色，遇到狀況看顏色就知道大致方向。

🟢

綠燈・日常普遍

溢奶、長牙、紅疹、便秘⋯多數會自行緩解。居家觀察：注意活力、食慾、尿量。

🟡

黃燈・突發狀況

發燒、上吐下瀉、跌倒撞到⋯先做居家處理＋觀察 24-48h。有紅旗症狀就安排看診。

🔴

紅燈・嚴重急症

抽搐、嘴唇紫、誤食、撞頭意識不清⋯立刻急診或撥 119，不能等門診。

03 · 怎麼用

三種找答案的方式

小亨堡看得懂自然語言，怎麼問都行。

1

直接打字描述

不用記分類，把寶寶現在的狀況打進去就好——例如「發燒 38.5」、「吐奶很多次」、「屁股紅一片」。

2

選分類 → 選月齡

不確定關鍵字時，從「發燒 / 餵食 / 呼吸 / 皮膚⋯」分類進去，再選寶寶月齡，會列出該月齡常見的題目。

3

點熱搜關鍵字

首頁有 6 個熱搜：發燒 / 吐奶 / 腸絞痛 / 紅疹 / 噎到 / 便秘，一鍵直達。

👩

05 · 急救 SOP

急救步驟：哽塞、CPR、燙傷⋯

緊急時你不會記得書怎麼說，但能打開手機照著一條一條做。

🍼 嬰兒哽塞救命 👶 哈姆立克 💗 嬰幼兒 CPR 🌡 發燒處置 🔥 燙傷處理 🤝 抽搐 / 熱性痙攣 🤕 頭部撞傷 💊 毒物吞入 🌿 嚴重過敏
提醒：急救情境第一步永遠是「判斷意識 → 叫 119 → 立即操作」。操作中可開擴音，讓救護人員邊指導邊評估。
不要倒提雙腳、不要手指挖喉嚨。
06 · 問診清單

15 秒產生「求救卡」

媽媽心慌時很難條理表達。問診清單把該補的資訊問完，自動產出整齊的求救文字。

八題互動式問答（可跳過）：

月齡 性別+體重 主要症狀 開始時間 體溫 精神 喝奶吃飯 已做的處置
填完按一鍵複製，就能貼到社群 / LINE / 給醫師看，不用再重複講 N 次。
